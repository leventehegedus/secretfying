# Plan: phase 5, apps/web

Goal: the SPA in `apps/web` over the existing REST API. Read-only pages work without a token; writes send
`Authorization: Bearer <API_TOKEN>` from localStorage. Hungarian default, English toggle.

## Constraints

- React 18 + Vite + Tailwind + shadcn/ui, React Router, TanStack Query. Strict TS, no `any`.
- Server state only via TanStack Query (`useQuery`/`useMutation`), no `useEffect` fetching.
- Types come from `@fdw/shared` (`Watch`, `WatchInput`, `Deal`, `Settings`, `DEFAULT_SETTINGS`...);
  validate API responses with the shared Zod schemas where one exists. No deal maths in web.
- Missing data shown as missing ("nincs adat" / "no data"); never 0 or a made-up price.
  `insufficient_history` stats are `null`: show "kevés adat" / "not enough history".
- `source: "fixture"` observations are labelled "demo".
- Lean deps: tailwindcss v4 (`@tailwindcss/vite`), shadcn components copied into
  `src/components/ui` (only the ones used), `@tanstack/react-query`, `react-router` (v7),
  `recharts` for the history chart. No i18n library: a typed dictionary.
- Money via `Intl.NumberFormat(lang, { style: "currency", currency: "EUR" })`.

## API used (all under `/api`, see `apps/api/src/routes`)

| page / action      | endpoint                                                          |
| ------------------ | ----------------------------------------------------------------- |
| dashboard          | `GET /deals?status=`, `GET /refresh/status`, `GET /quota`, `GET /providers` |
| refresh button     | `POST /refresh` (409 running, 429 1/min)                          |
| watches list/CRUD  | `GET/POST /watches`, `PUT/DELETE /watches/:id`                    |
| destination search | `GET /places?q=`                                                  |
| watch detail       | `GET /watches/:id/prices?range=30d\|90d\|365d` (series + daily median/p10) |
| history            | `GET /deals?from=&to=&status=`                                    |
| settings           | `GET/PUT /settings`, `POST /notify/test`                          |

401/503 on a write: show "token missing/invalid" and open the token dialog.

## Tasks (one commit each)

1. **Tooling**: tailwind v4 plugin, `@/` alias, shadcn init (button, card, input, label, select, switch,
   table, badge, dialog), Vitest + Testing Library + jsdom config for web.
2. **Core**: `lib/api.ts` (fetch wrapper: JSON, bearer from localStorage on non-GET, typed `ApiError`
   with status), `lib/format.ts` (money, date), `i18n/` (`hu`/`en` dict with identical keys enforced by
   type, `useT()` + language in localStorage, initial value from settings `language`), token dialog,
   app shell with nav + language toggle, router, QueryClient. Tests: api wrapper header/error, dict key
   parity.
3. **Dashboard** (`/`): last run card (status, time, counts, provider statuses), quota remaining per
   provider, refresh button with mutation + error states, current deals table (route, dates, price,
   reasons, status badge candidate/verified/stale, cached vs live label). Test: deals table renders
   missing price fields as missing.
4. **Watches** (`/watches`): list with active switch, create/edit dialog (form for `WatchInput`, place
   autocomplete via `/places`, client validation with `WatchInput.safeParse`, server Zod errors shown per
   field), delete with confirm. Test: form rejects invalid stay.
5. **Watch detail** (`/watches/:id`): range tabs, line chart of observations with median and p10 lines
   (gaps where stats are null), table of latest observations with demo/cached labels, insufficient
   history notice.
6. **History** (`/history`): deals by date range + status filter.
7. **Settings** (`/settings`): form for every `Settings` key with defaults hint, save, "send test
   Telegram" button, token management (set/clear).
8. **Verify**: `pnpm lint && pnpm typecheck && pnpm test && pnpm dup`, `pnpm build`; Playwright pass over
   every page against `DRY_RUN` api (fixture data); update `docs/PROGRESS.md`.
